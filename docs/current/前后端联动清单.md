## 接续任务执行纪律

用户已指定 DeepSeek V4.1 Flash，授权积极调用子智能体以加速独立模块。由任务主线程维护本清单与 UI 基准，分配互不冲突的文件所有权；可按前端接入、后端合同、旧前端归档拆分并行，涉及同一文件先协调，根 package/入口配置由一人整合。子任务须知道共享工作区，不回退他人改动。

先登记差异再修可确定的接入问题。新 UI 缺后端支持时先给出最小合同与影响；新增独立接口可按已批准产品需求实施，核心架构/数据库/识别规则变化需先出方案。旧版有但新产品明确舍弃的功能不恢复。不可联通的外部账号或设备记录限制，别反复重试或伪装成功。

验证只覆盖必要变更，不反复跑全量、不做 EXE。不清空真实库，不用真实凭据作夹具，不删除历史任务。旧前端迁移前校验解析后的绝对源路径与目标均在当前仓库及指定归档范围内，保留结构，不使用跨 shell 拼接移动/删除命令。

任务结束更新本清单、归档映射与实际验证结论，主线程审查范围并只提交该任务文件；已有未提交后端工作单列，不擅自混入提交。前端 UI 不再增设平行知识库；本文件记录联动事实与缺口，不重复定义视觉规则。
