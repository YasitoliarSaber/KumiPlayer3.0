# 页面需求

> 面向：产品设计方
> 用途：说明新前端需要设计哪些页面、每个页面的目的、要让用户看到什么、要让用户能做什么。
> 说明：本文件**只描述页面目标、展示内容与用户操作**，不描述界面长相，也不涉及任何技术实现。
> 本文件是本次设计的主要依据。

## 1. 产品需要哪些页面

| # | 页面 | 一句话目的 |
|---|---|---|
| 1 | 首次引导 | 让新用户完成最小配置后开始使用 |
| 2 | 首页 | 作为打开软件后的落地页，展示媒体库入口与推荐内容 |
| 3 | 分类 / 新番 | 按分类与来源浏览海报墙，并跟进未完结作品 |
| 4 | 搜索 | 用关键词找到作品 |
| 5 | 收藏 | 浏览用户收藏的作品 |
| 6 | 最近观看 | 继续上次没看完的内容，回顾观看历史 |
| 7 | 作品详情 | 看一部作品的全部信息与剧集，并从这里播放 |
| 8 | 媒体管理 | 导入媒体、确认识别结果、跟踪任务、执行维护 |
| 9 | 设置 | 配置来源、网盘、资料源、播放器、外观与账号 |
| 10 | 播放调校 | 调节内置播放器的参数并验证 |
| 11 | 启动与故障恢复 | 启动过程中以及出问题时的兜底界面 |

其中，**媒体管理**与**作品详情**承载的操作最多，是设计的重点与难点。

## 2. 全局外壳

所有页面共享的外层结构，需要承载：

| 需要支持 | 说明 |
|---|---|
| 主导航 | 进入首页、分类 / 新番、收藏、最近观看、媒体管理、设置 |
| 前进与后退 | 页面之间的历史往返 |
| 全局搜索入口 | 输入关键词后进入搜索结果；清空关键词回到原来的页面 |
| 窗口控制 | 最小化、最大化、关闭 |
| 后台状态 | 让用户随时知道是否正在扫描、整理资料或准备图片 |
| 连接状态 | 后台是否在线、是否正在恢复 |
| 状态呈现 | 加载中、空状态、失败、无网络 |

设计方可以重新定义导航模型（例如改用其他导航结构），但以上能力必须存在。

## 3. 逐页需求

### 3.1 首次引导

- **目的**：新用户第一次打开软件时，完成"能开始用"所需的最小配置。
- **需要展示**：当前配置状态；需要用户决定的事项（媒体来源、播放器、可选的账号凭据）；每项的当前状态与是否已具备。
- **需要支持的操作**：保存配置；跳过引导直接进入软件（之后再从设置进入）；从设置重新进入引导。
- **关键语义**：引导可以跳过；跳过后软件必须可正常使用，且要提示"跳过了什么、之后在哪里补"。

### 3.2 首页

- **目的**：打开软件后的第一印象，快速进入想看的收藏。
- **需要展示**：媒体库概览入口；推荐 / 精选位置；继续观看；收藏或最近活动的入口。
- **需要支持的操作**：进入作品详情；跳转到分类、收藏、最近观看。
- **关键语义**：媒体库尚未发布时（首次导入还在准备）需要有明确的等待或引导状态，不能呈现为空库。

### 3.3 分类 / 新番

- **目的**：这是媒体库的主体浏览界面。
- **需要展示**：
  - 分类维度：动画剧集、动画电影、真人剧集、真人电影，以及"新番"视图。
  - 来源筛选：全部，以及按来源（本机 / 各网盘）筛选。
  - 排序维度：最近、标题、评分、年份、集数等。
  - 卡片展示：海报或剧照；卡片尺寸可调。
  - 每张卡片需要承载的信息：标题、年份、评分、集数（含已看数量一类的进度信息）、是否在追更、图片来源是否就绪。
  - 新番视图需要额外展示：来源的更新状态、最近更新时间、待处理的新增内容。
- **需要支持的操作**：切换分类与来源；切换排序与卡片尺寸；打开作品详情；发起新番导入；刷新状态。
- **关键语义**：
  - 收藏规模可达上千部，浏览必须流畅。
  - 进入页面只查看状态，不应触发耗时的后台动作。
  - 缺图的作品不应以空壳形式出现在墙上。

### 3.4 搜索

- **目的**：用关键词快速定位作品。
- **需要展示**：匹配结果；无结果状态；搜索进行中状态。
- **需要支持的操作**：输入关键词；清空关键词回到上一个页面；打开结果作品。

### 3.5 收藏

- **目的**：集中浏览用户标记为收藏的作品。
- **需要展示**：收藏作品；收藏为空的引导状态。
- **需要支持的操作**：打开详情；取消收藏。

### 3.6 最近观看

- **目的**：接着上次看，或者回顾看过什么。
- **需要展示**：观看历史条目（作品、集、看到哪里、时间）；"继续"入口。
- **需要支持的操作**：从某条记录继续播放；打开作品详情；清理历史记录（若产品提供该操作，需明确确认）。

### 3.7 作品详情

本页承载的操作为全产品最多，按能力块列出。

| 能力块 | 需要展示 | 需要支持的操作 |
|---|---|---|
| 基本信息 | 标题、原始标题、年份、类型、评分、简介、题材、制作方 | 播放作品 |
| 视觉 | 海报与背景图（含图片来源是自动还是用户上传） | 上传 / 更换封面、恢复为自动资料 |
| 季与集 | 季度列表、每季剧集列表、集号与标题、每集观看状态、每集是否可播放 | 选择剧集播放、切换季度、跳到指定集 |
| 播放进度 | 上次看到的位置、是否已看完 | 继续播放、标记已看 / 未看 |
| 手动纠错 | 当前生效的标题与封面是否为用户指定 | 修改标题、上传封面、恢复自动资料 |
| 收藏与状态 | 收藏、在追 / 搁置 / 弃剧等状态 | 切换收藏、切换观看状态、写备注 |
| 资料匹配 | 匹配候选列表（标题、年份、来源、评分）、当前绑定、资料更新时间 | 搜索候选、确认匹配（可按作品或按季度）、重新获取资料、重试失败项 |
| 账号集成 | 账号登录状态、匹配结果、收藏状态、同步进度 | 匹配、同步、设置收藏状态 |
| 关联内容 | 演员、相关作品 | 跳转到相关作品 |
| 管理操作 | 删除会影响什么的预览说明 | 预览删除、确认删除（**不会删除真实影片文件**）、打开影片所在文件夹 |
| 追加剧集 | — | **不提供**（产品当前无此能力） |

- **关键语义**：手动修改过的标题与封面，必须在界面上明确表示"这是你设置的"并提供恢复入口。

### 3.8 媒体管理

这是产品的功能核心，内部由三种模式组成：**媒体库总览**、**导入媒体**、**媒体库维护**。

#### 3.8.1 媒体库总览

- **需要展示**：已导入来源的列表。每个来源需要呈现：名称、内容来源与导入方式（这是两件不同的事）、识别到的范围、是该来源声明是"已完结"还是"持续更新"、健康状态、作品数量、待处理数量、最近一次扫描时间、覆盖了哪些位置。
- **需要支持的操作**：新建导入；继续处理某个来源未完成的导入；重命名来源；移除来源（必须明确确认，且要说明"只移除媒体库记录，不动真实文件"）；进入维护模式。
- **关键语义**：空库状态要引导用户去导入，而不是显示空白页。

#### 3.8.2 导入媒体

**四种入口**（用户需要在这里选择用哪种方式导入）：

| 入口 | 用户要提供什么 | 产品要做什么 |
|---|---|---|
| 本地目录 | 选择一个本机文件夹 | 读取该目录下的内容 |
| 目录清单文件 | 选择网盘导出的清单文件 | 从清单里读出目录结构与内容 |
| 网盘目录地址 | 选择一个网盘上的目录 | 从网盘读取目录内容 |
| 清单文件 + 网盘目录 | 两者都提供 | 用清单确定内容，用网盘确认可达性 |

**导入过程需要覆盖的阶段**：

1. **选择来源**：选择入口与范围（已完结 / 持续更新），必要时选择网盘连接。
2. **扫描中**：展示进度（已处理 / 总数、当前目录）与过程信息；可取消；可离开页面，之后从来源卡片回来继续看。
3. **识别预览**：展示识别结果——识别出的作品、季与集、每部作品识别的证据摘要、以及**需要用户处理的条目**（说不清是哪部作品、有多种可能、路径无法确认等），每条要给出原因。
4. **人工修正**：对个别条目做覆盖修正（这属于用户数据，不能改变原始证据）。
5. **确认导入**：确认后正式进入媒体库。
6. **执行中**：展示资料获取与图片准备进度；可离开页面；失败项可重试。
7. **结果与失败项**：展示完成情况与需要处理的失败项。

- **关键语义**：未确认的识别结果不得进入媒体库；待处理项必须被用户明确处理；准备完成后作品才出现在媒体库。

#### 3.8.3 媒体库维护

- **需要展示**：媒体库规模与摘要（作品、集、图片、任务等）；可执行的维护操作及其影响范围；诊断摘要。
- **需要支持的操作**：执行受控维护操作；查看诊断信息。
- **关键语义**：维护操作必须明确说明影响范围，且不得删除真实影片。

### 3.9 设置

七个分类，各自需要承载：

| 分类 | 需要展示 | 需要支持的操作 |
|---|---|---|
| 应用 | 窗口与托盘行为、后台连接监测状态、程序运行方式 | 修改应用级开关、重启后台、打开日志、导出诊断信息 |
| 外观 | 主题、风格、动效、海报墙外观与卡片密度 | 调整外观偏好（需即时生效并记住） |
| 媒体来源 | 已登记的本地目录及其名称与内容范围；启动更新与定时更新策略 | 增删改本地目录、设置内容范围、配置更新策略 |
| 网盘 | 连接配置与连接测试、远端根目录、内容路由（哪个远端路径对应哪个内容来源与本机盘符） | 新建 / 测试连接、配置路由、浏览远端目录 |
| 资料源 | 资料服务的凭据是否已配置、连接测试、图片问题的检测与修复 | 保存凭据、测试连接、执行图片检测与修复 |
| 播放器 | 内置播放器状态与参数、画质增强相关参数 | 调整参数、保存、运行播放测试 |
| 账号 | 账号登录状态、当前用户、同步偏好 | 登录 / 退出、刷新状态、配置同步 |

- **关键语义**：凭据只显示"是否已配置"，永不显示明文；连接测试要给出明确成功 / 失败原因。

### 3.10 播放调校

- **目的**：在不离开设置的情况下调节内置播放器。
- **需要展示**：当前参数值、播放器运行状态、是否有其他操作正在占用。
- **需要支持的操作**：修改参数、保存、运行播放测试。
- **关键语义**：参数改动对之后播放的视频生效；播放进行中不应允许并发调参。

### 3.11 启动与故障恢复

- **启动过程**：展示启动进度；启动失败时给出可操作的原因与出路。
- **故障恢复页**：重新加载界面、重启后台、打开日志位置、导出脱敏诊断信息。
- **关键语义**：恢复页是最后一道兜底，任何时候都必须可达。

## 4. 所有页面都要覆盖的状态

设计每一页时都必须交代以下状态，这是验收的一部分：

| 状态 | 要求 |
|---|---|
| 加载中 | 明确的进行中反馈，不使用闪烁或布局跳动 |
| 空 | 区分"这个列表确实没有内容"和"内容还没准备好" |
| 未发布 / 准备中 | 首次导入尚未完成时，媒体库应表现为"正在准备"而不是"空" |
| 后台进行中 | 有任务在跑时，界面仍可正常使用，并能让用户看到进度 |
| 失败 | 给出可读的原因与下一步（重试、修改配置、跳过） |
| 部分失败 | 整体成功但有若干项失败时，必须把失败项单独列出来 |
| 无网络 | 网盘、资料服务不可用时的降级表现 |
| 权限 / 凭据缺失 | 需要用户去配置时的引导 |
| 内容很长 | 长标题、长简介、超长目录名的截断与展开 |
| 窄窗口 | 窗口被缩小时仍可用 |
| 键盘操作 | 主要操作可仅用键盘完成，焦点状态清晰 |
| 三套外观 | 每页在全部外观与动效档位下都成立；动效关闭档必须无动画 |
