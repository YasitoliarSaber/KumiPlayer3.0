Reproducibility
  evidence.json records the SHA-256 of each archive, patch, upstream file and
  current redistributed source. local-source snapshots preserve current bytes
  and line endings. Git patch application must disable core.autocrlf while
  checking byte equivalence; Windows global autocrlf otherwise changes bytes.
